# ChatGPT → Codex 需求交接

## 目前需求
確認「AI與你企業平台」實際原始碼位置，先檢查 PDF／電子書解析流程，再評估隔離整合 OCR。

## 尚缺資訊
- 本機原始碼路徑或原始碼檔案。
- 原始碼應放入這個範本 repo，還是另一個專屬 repo。
- 平台的啟動方式、依賴與可使用的測試文件。

## OCR 驗收條件
- 保留原版與回退方法，採獨立分支或隔離環境。
- 確認可用後整合 OCRmyPDF、Apple Vision OCR（Mac）、Tesseract chi_tra+eng。
- Microsoft Table Transformer 按需啟動，驗證實際表格結構與內容對齊。
- 相同測試集比較原版與新版，涵蓋原生文字、掃描頁、內嵌圖片、繁中英文、表格與閱讀順序。
- 建立核對過的正確答案，記錄 CER/WER 的正規化及中文分詞方式。
- 報告圖片文字、表格結構、閱讀順序、耗時、峰值記憶體與成本；區分冷啟動與暖啟動。
- 未實測不得宣稱提升；合成測試與真實電子書結果分開報告。
